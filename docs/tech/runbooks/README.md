# Runbooks

Procedimentos operacionais do Aysha Leilões, escritos pelo devops-sre (e roteiros de teste manual, pelo qa-engineer). Formato de cada runbook: **Sintoma** → **Diagnóstico** (comandos literais) → **Correção** → **Verificação**. Um arquivo por procedimento, nome descritivo em kebab-case (ex.: `coleta-falhou.md`, `rollback-deploy.md`, `teste-manual-funil-compra.md`).

Ainda não há runbooks: serão criados conforme as rodadas técnicas acontecerem (append-first; não apague runbook que ainda descreve o sistema real).
