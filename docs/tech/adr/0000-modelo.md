# ADR 0000 — Modelo (copie este arquivo para NNNN-titulo.md)

- **Status**: proposto | aceito | substituído por NNNN
- **Data**: AAAA-MM-DD
- **Autor**: agente ou mantenedor

## Contexto

O problema ou força que exige a decisão (com números e fontes quando houver).

## Decisão

O que foi decidido, em uma frase afirmativa.

## Alternativas consideradas

Cada alternativa com o motivo do descarte.

## Consequências

O que fica melhor, o que fica pior, o que passa a ser proibido/obrigatório, e o que faria rever esta decisão.
